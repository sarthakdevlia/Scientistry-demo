# Scientistry — 3D website concept

A scroll-driven 3D concept site for Scientistry (scientistry.in): the Anti Acne bottle, Bicomide explained inside the bottle, the actives as 3D molecules, and the full range on a shelf; then a skin quiz, an ingredient explorer and FAQs with Product and FAQ structured data. Static: no build step, no server.

- `index.html` — the whole site (Three.js scene, Lenis scroll, quiz, explorer, styles, JSON-LD).
- `img/` — Scientistry's own product photos and "Actives" cards, taken from scientistry.in.

Share it as a **link**: an HTML file sent on WhatsApp does not run the 3D on iPhone.
